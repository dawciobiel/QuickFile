# Funkcje aplikacji

- Interfejs GUI oparty na PyQt5:
    - Ekran główny z nawigacją.
    - Formularze wejściowe i walidacja.
- Moduły przetwarzania danych:
    - Import/eksport danych (CSV/JSON).
    - Walidacja i normalizacja.
- Logging i obsługa błędów:
    - Zapisywanie zdarzeń do pliku log.
- Testy:
    - Jednostkowe testy podstawowych funkcji.
