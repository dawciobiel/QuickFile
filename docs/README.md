# Dokumentacja projektu

## Szybki start
1. Utwórz wirtualne środowisko:
   \`python -m venv .venv\`
2. Aktywuj środowisko i zainstaluj zależności:
   \`pip install -r requirements.txt\`

## Zawartość katalogu docs
- \`README.md\` — ten plik (spis treści).
- \`application-features.md\` — lista funkcji aplikacji.
- \`architecture.md\` — opis architektury.
- \`usage.md\` — przykłady uruchomienia.
- \`contributing.md\` — zasady współpracy.
