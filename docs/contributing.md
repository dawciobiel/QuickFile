# Contributing

Dziękujemy za chęć współpracy. Krótkie zasady:

1. Fork → branch feature/issue-123 → PR z opisem zmian.
2. Formatowanie kodu: uruchom \`ruff\` i popraw styl przed PR.
3. Testy: dodaj testy dla nowych funkcji (`pytest`).
4. Commit messages: krótkie i rzeczowe (np. \`feat: dodaj eksport CSV\`).
5. Review: PR powinien mieć co najmniej jedną akceptację zanim zostanie scalony.
